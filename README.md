# media-player · 载荷媒体播放

> **多路图像流是至少四处界面的主体内容，却与业务面板同层，无法独立压测与交付。**

本仓当前为**立项阶段**：只冻结了需求，尚未开始实现。

---

## 它解决什么问题

多路图像流是至少四处界面的主体内容，却与业务面板同层，无法独立压测与交付。

## 做 / 不做

| 做 | 不做 |
|---|---|
| 通道与源（本地视频 / 图像流序列帧） | 不做地图（禁止 import 地图模块） |
| 播放控制（进度、音量、倍速、全屏、单帧） | 不做业务语义 |
| 多路同屏（≥6 路）与节流 | 不做远程流接入（仅留扩展点） |
| 叠加层（锁定框、倍率、时间戳） | 不做转码与推流 |
| 无素材降级与状态可观测 |  |
